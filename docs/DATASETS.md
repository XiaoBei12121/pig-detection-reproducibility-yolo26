# Datasets

The original image data and annotations of **PigDetect** and **PigLife** are **not redistributed**
in this repository. All experiments were run on local copies obtained from the official providers.
This repository ships the exact split lists, the preprocessing scripts and the analysis results.

---

## PigDetect

Source:
DOI: https://doi.org/10.25625/I6UYE9
Reference: Henrich, J., Post, C., Zilke, M., Shiroya, P., Chanut, E., Mollazadeh Yamchi, A.,
Yahyapour, R., Kneib, T., & Traulsen, I. (2026). *Benchmarking pig detection and tracking under
diverse and challenging conditions.* Computers and Electronics in Agriculture, 241, 111264.

This repository does not redistribute the original images.
Download the dataset from the original provider and place it under:

```
data/PigDetect/
```

Expected structure:

```
data/PigDetect/images/
data/PigDetect/labels/
```

The exact train/val/test image lists used in the paper are provided in:

```
splits/pigdetect/
```

Notes on the splits used here (project-level, **not** the benchmark default):

- `train.txt` 2411 / `val.txt` 270 — camera-prefix group-aware 9:1 split of the official
  2,681-image development pool (seed 42). Regenerate with `scripts/data/prepare_pigdetect.py`.
- `test.txt` 250 — the official benchmark test split, used as the *exploratory* test set in the paper
  (all 250 images come from the `danuma` source group).
- `cross_scene_{train,val,test}.txt` 1098 / 129 / 450 — single-source-group held-out experiment:
  train/val use the non-`danuma` groups, test is the `danuma` group. This is **not** a full 4-fold
  leave-one-source-out evaluation.
- `final_{train,val,test}.txt` 2226 / 251 / 204 — final-protocol holdout built *after* exploratory
  development (seed 2026, `scripts/data/split_final_test.py`). The 204 held-out images are disjoint
  from the final-protocol train/val sets and from the 250-image exploratory test, but they are drawn
  from the same historical development pool (186 of them previously appeared in the exploratory
  train split and 18 in the exploratory val split). They are therefore **not** an untouched external
  test set for the already-developed models; they are unseen only for the re-trained final-protocol
  models (E0_ft / E5_ft).

## PigLife

Source:
https://data.aifarms.org/view/piglife

The original PigLife data are not redistributed in this repository.
Users must obtain the dataset according to the provider's license.

**Ethics**: animal-experiment ethics approval or exemption is governed by the original dataset
publication, its data statement and the provider's license terms. This repository does not repeat or
infer any approval number.

Expected structure:

```
data/PigLife/
```

The exact group-aware split manifests used in the paper are provided in:

```
splits/piglife/
```

Notes:

- Delivered detection data consist of **1704 fully annotated training images** and **426 fully
  annotated test images** (single class `pig`, 3840×2160). The released JSON `images` arrays contain
  many repeated entries (17505 / 4474 rows referencing only 1704 / 426 unique files), and the
  package contains **no background (pig-free) frames**. Only images with confirmed complete
  annotations are used, as described in the manuscript.
- `train.txt` 1441 (32 camera groups) / `val.txt` 263 (6 camera groups) / `test.txt` 426 — camera-group
  aware 85:15 split of the official training partition (seed 42), generated by
  `scripts/data/prepare_piglife.py`. `group_manifest.csv` records the image-group → split assignment
  so the split can be verified without the images.
- Images are pre-resized to a longest side of 1280 (aspect preserved, JPEG q92) before the detector's
  standard 640×640 letterbox pipeline; PigDetect did not use this intermediate pre-resizing step.
  A 640-input coordinate audit of both test sets is provided in `results/statistics/`.

## Class definitions

Both datasets are single-class: `0: pig`.
