# Results traceability

Every table, figure and statistic in the manuscript maps to a source file and (where applicable) a
generating script in this repository. Regenerate everything with:

```bash
python scripts/analysis/reproduce_statistics.py --figure   # statistics + Figure 10
python scripts/analysis/reproduce_tables.py                # Tables 1–18  -> results/generated/
python scripts/analysis/rank_stability.py                  # rank tables + Figure 11
```

### ⚠ Confidence threshold — Table 6 is NOT `occlusion_analysis.json`

`results/error_analysis/error_analysis_conf025.json` uses **confidence ≥ 0.25** and is the source of
manuscript Tables 6 and 8.
`results/occlusion/occlusion_analysis.json` uses a **different (lower) confidence configuration**, so
its recall values are systematically higher. It is retained for audit only and **is not** the source
of Table 6. See `results/occlusion/README.md`.

Verification for the conf≥0.25 configuration (PigDetect test, 5436 GT instances):

| Level | Instances | E0 misses | E5 misses | E0 recall | E5 recall |
|---|---:|---:|---:|---:|---:|
| Low | 1715 | 24 | 21 | 0.9860 | 0.9878 |
| Medium | 1385 | 38 | 32 | 0.9726 | 0.9769 |
| High | 2336 | 208 | 210 | 0.9110 | 0.9101 |

## Run manifests

`manifests/runs_pigdetect.csv` (27 runs), `manifests/runs_piglife.csv` (9 runs × best/last),
`manifests/runs_yolo11_replication.csv` (6 runs × best/last) list config, seed, hyper-parameters,
checkpoint rule, best epoch, validation/test metrics, parameters, GFLOPs and the result file for
every run — i.e. every manuscript number can be traced to one run.
