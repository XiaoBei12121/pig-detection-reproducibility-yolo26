# Run manifests

Three CSV manifests list **one row per run** so that every number in the manuscript can be traced to
a single trained model:

| File | Rows | Content |
|---|---:|---|
| `runs_pigdetect.csv` | 27 | E0–E6 (seed 42), the multi-seed runs (E0/E5 × {1,7,21,100}, E1/E3 × {1,7}), the deterministic repeats (E0/E5 × 3 runs), the final-protocol runs (E0_ft/E5_ft) and the cross-scene runs (E0_cs/E5_cs) |
| `runs_piglife.csv` | 18 | 9 PigLife runs (E0/E5 × {42,1,7}; E1/E2/E3 × 42) × both checkpoint rules (best/last) |
| `runs_yolo11_replication.csv` | 12 | YOLO11s baseline and +CA × seeds {42,1,7} × both checkpoint rules |

## Columns

| Column | Meaning |
|---|---|
| `run_id` | unique run identifier used in the paper |
| `model`, `config` | variant name and the exact model YAML (`configs/…`) |
| `dataset`, `seed` | dataset/split name and random seed |
| `epochs`, `imgsz`, `batch`, `optimizer`, `lr0`, `momentum` | training protocol (identical for all runs: 100 / 640 / 4 / MuSGD / 0.01 / 0.937) |
| `checkpoint_rule` | `best` = validation-selected, `last` = epoch-100 (post-hoc sensitivity only) |
| `best_epoch`, `val_map50`, `val_map5095` | validation-selected epoch and its validation metrics |
| `test_map50`, `test_map5095`, `precision`, `recall` | metrics on the frozen test split of that dataset |
| `params_m`, `gflops` | parameters of the trained checkpoint and GFLOPs at 640×640 |
| `result_file` | locked result file in this repository holding the run's test metrics |

## Notes

- Test metrics for the repeated runs (`E0_rep2/3`, `E5_rep2/3`) are identical to their seed-42 run
  because the reruns produced bit-identical predictions; the `result_file` column says so explicitly.
- Validation metrics come from each run's `results.csv` (Ultralytics); test metrics were produced by a
  single post-training evaluation of that checkpoint with the same protocol for every run.
- The manifests are generated by `scripts/data/build_manifests.py` from the (private) development
  repository; the script is shipped for auditability but needs the original run directories to run.
